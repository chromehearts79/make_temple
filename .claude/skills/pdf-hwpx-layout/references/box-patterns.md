# 상자 속 상자 유형집

한전KDN 경영실적보고서 50쪽(인쇄 30쪽)을 원본 화면과 맞춘 v5에서 정리한 유형이다. 코드는 `scripts/kdn_p50.py`에 그대로 있다. 다른 쪽도 같은 디자인 체계를 쓰므로 이 표에서 찾아 쓴다.

## 먼저 디자인 목록을 만든다

레시피를 쓰기 전에 `page.png`(또는 원본 화면)를 확대해 보고, 아래 항목을 쪽의 위에서 아래로 빠짐없이 적는다. 글자층에는 이 정보가 거의 없고, 놓치면 나중에 사용자가 하나씩 지적하게 된다.

- 줄 안의 작은 상자: 상자 글자, 위치(줄 앞·가운데·끝), 채움 농도 또는 테두리, 글자색
- 번호 상자: 네모인지 동그라미인지, 검은 채움인지 테두리만인지. 원문에서 그림이면 글자층에 번호가 없다
- 칸 안에 들어간 상자: 카드 아래 성과 상자처럼 바깥 테두리 안쪽에 여백을 두고 놓인 상자
- 제목 줄 끝의 꼬리표(예: `지적사항 개선`)와 아이콘
- 회색 농도: 같은 쪽 안에서 옅음·중간·짙음·검정이 몇 단계인지
- 괄호 속 작은 글자처럼 글자 크기가 섞인 곳

`pdf_coords.py`가 알리는 `inline_tags`는 이 목록의 초안이다. 위치와 채움색까지 알려 준다. 다만 그림으로 된 상자, 그림 속 글자, 표 라벨 칸 때문에 빠지거나 더 잡힐 수 있으므로 그림과 대조해 고친다. 원본 PDF가 없으면 사용자에게 그 쪽 화면을 받아 같은 목록을 만든다.

## 유형과 코드

모든 줄 속 상자는 `layout.boxed_line(조각들, 안쪽 너비, 줄 높이, ...)` 하나로 만든다. 조각은 읽는 순서대로 글자열과 `tag(...)`를 섞는다. 안쪽 너비는 바깥 칸 너비에서 좌우 여백(기본 320+180, 지정했으면 그 값)을 뺀 값이다.

```python
from hwpx_layout import tag
light_tag = border("#D9D9D9")                                          # 옅은 회색, 검은 글자
mid_tag = border("#808080")                                            # 중간 회색, 흰 글자
dark_tag = border("#3A3A3A")                                           # 짙은 회색, 흰 글자
black_num = border("#262626")                                          # 검은 번호 상자
outline_tag = border("#FFFFFF", top="thin", bottom="thin", sides="thin")  # 테두리 상자
```

| 유형 | 원본 예 | 코드 |
|---|---|---|
| 줄 앞 꼬리표 (글머리 뒤) | `∙ [환경분석] 육아휴직 등 …` | `boxed_line(["∙", tag("환경분석", light_tag, "#161616", size=950), 나머지], 45500, 1300, size=1040, ratio=78)` |
| 제목 앞 꼬리표 | `[예측 고도화] 정현원 실시간 모니터링` | `boxed_line([tag("예측 고도화", mid_tag, size=950), 제목], 카드폭-300, 1400, bold=True, align="CENTER")`, 바깥 칸 여백 150/150 |
| 줄 끝 꼬리표 | `… 지역 전문사원 [개선]` | `boxed_line([앞, tag("개선", mid_tag, size=950)], 24250, 1350)` |
| 줄 가운데 꼬리표 | `… 권역(충청)[개선], 지역불균형 완화` | `boxed_line([앞, tag("개선", mid_tag, size=950), 뒤], 24250, 1350)` |
| 테두리 꼬리표 | `「KDN-Job담회」 [신규] - 권역별 …` | `tag("신규", outline_tag, "#161616", size=950)` |
| 검은 번호 상자 | `❶ [내부] …`, `❶ 찾아가고, 알리고` | `tag("1", black_num, size=950, width=1100, height=1150)` (줄보다 낮은 상자) |
| 테두리 번호 상자 | 추진전략 `[1] 공공 일자리 확대` | `tag("1", outline_tag, "#161616", size=950, width=1100, height=1150)` |
| 제목 줄 끝 상자 | `나. … 청년 일자리 창출 [☞ 지적사항 개선]` | `layout.section.extend(boxed_line([제목, tag("☞ 지적사항 개선", dark_tag, size=950, height=1450)], 49900, 1700, size=1320, ratio=83, bold=True, gap=240))` |
| 칸 안에 들어간 상자 | 카드 아래 `4직급 현원 충원율 100% 달성` | 바깥 칸 `cell(..., [layout.nest([[cell(0, 카드폭-300, 높이-300, 글, border("#DCDCDC"), margin=dict(left=150, right=150))]])], border(bottom="soft", sides="soft"), margin=dict(left=150, right=150, top=0, bottom=150))` |

카드처럼 제목·본문·성과가 한 테두리로 묶인 경우는 행마다 테두리를 나눈다. 제목 칸은 위 굵은 선과 아래 옅은 선, 본문 칸은 좌우 선만, 성과 칸은 좌우와 아래 선을 쓰고 그 안에 회색 상자를 넣는다.

## 원문 글자와 상자

- 꼬리표 글자가 글자층에 있으면(예: `신규`, `개선`, `환경분석`) 그 글자를 잘라 상자에 넣는다. 레시피는 `split_tag(줄, "개선")`처럼 줄에서 찾고, 없으면 멈춘다. 같은 낱말이 줄에 두 번 나오면 마지막 것을 상자로 본다.
- 번호 상자와 아이콘이 그림이던 곳은 글자층에 없으므로 번호를 직접 넣는다. `check_hwpx.py`의 원문 대조에는 영향이 없다.
- 동그라미 번호(❶)는 상자로 만들지 않는다. KS X 1001 밖의 기호라 ①로 쓴다(`layout-workflow.md`의 기호 표).

## 폭과 장평

- `text_width()`는 한글을 1em, 공백을 0.35em, ASCII를 0.6em으로 넉넉히 센다. 그래서 실제 한글에서는 줄 끝 상자 앞에 몇 pt 빈칸이 생길 수 있다. 대신 줄이 넘어가지 않는다.
- 조각 폭의 합이 안쪽 너비를 넘으면 `boxed_line`이 그 줄의 장평을 72까지 한 단계씩 낮춘다. 그래도 넘으면 가장 긴 글자 칸을 줄이고, 그 칸은 두 줄이 될 수 있다. 원본에서 괄호 속 글자가 작아 한 줄에 들어가는 줄이 여기에 걸린다. 이때 장평이 72 근처면 `hwpx_preview.py`로 보고 필요하면 글자 크기를 낮춘다.
- 상자 칸의 높이는 줄 높이와 같다. 번호 상자처럼 더 작아야 하면 `tag(..., height=)`를 준다.
