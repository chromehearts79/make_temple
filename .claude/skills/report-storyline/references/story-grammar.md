# 실적 서술 문법 — 지표별 목차

서술 문법은 지표명마다 따로 둔다. 쓰려는 지표의 파일 하나를 처음부터 끝까지 읽고 따른다. 파일마다 맨 위에 편람
원문(지표정의, 세부평가내용, 가중치)이 있고, 본문은 같은 8절(층마다의 서사 역할, 줄거리 규칙, 장면 형식, 제목, 문장과
기호, 증거의 사다리, 쪽 배분, 주의)이다. 규칙 끝 괄호의 숫자는 한전KDN 2025년도 보고서의 근거 인쇄쪽이다.

## 네 지표가 다른 곳 — 한눈에

| | 일자리 | 친환경･탄소중립 | 창업 및 경제활성화 | 상생･협력 및 지역발전 |
|---|---|---|---|---|
| 평가내용 수 | 4 | 1 | 4 | 3 |
| 여는 방식 | 지표 첫 설계(①-1 3축×3과제)가 지표 전체 목차, ③은 환류로 연다 | 설계 한 쪽(기관장 인용 → 환경 3+3 → 시사점 → 추진방향 3 → 과제 2×3)이 지표 전체 목차 | 지표 전체 설계 없이 네 장이 각자 체계도로 연다. 꼬리 칸은 협업체계·실행체계·성과목표 표 중 하나 | ①은 한 쪽 설계(시사점 4 → 전략과제 4×2), ②·③은 번호 없는 장 서두 |
| 회수 | 같은 말, 같은 순서(3×3 → 9칸) | 추진방향 문구 = 실행 과제 제목(한 글자도 같게) | 추진과제 칸 수 = 장면 수(6:6) | 추진방향 = 과제, 실행과제 = 장면(1:1) |
| 쪽 배분 | 본문 한 쪽에 과제 둘 | 한 쪽에 과제 하나, 마지막 과제 두 쪽 | 과제가 쪽을 넘기도 한다 | ①은 한 쪽에 과제 하나 |
| 장면 문제 여는 법 | 환경분석·현황·지원자 인용 | 추진목적, 국민 가상 질문 | 니즈 행, 고객 인용 박스, 추진배경 띠 | 추진배경 띠 + 협업체계(누구와) |
| 주요성과 단위 | 쪽 | 쪽·꼭지 | 쪽 → 과제 → 장면으로 내려간다 | 쪽(한 쪽 상자 둘도) |
| 고유 장치 | 「KDN-취업드림」 같은 프로그램 이름 | 감축 실적을 tCO2eq로 환산해 합산, "業의 특성을 살린" 반복 | 〈속도개선〉＋〈등록확대〉 같은 효과 라벨 2줄 | 고객 인용을 결과 뒤 증언으로 |

## 모든 지표에 같은 것 — 점검기 규칙

`scripts/storyline.py check`가 지표와 상관없이 확인한다. 각 지표 파일에서 `[점검]`이 붙은 규칙이 이것이다.

| 규칙 | 오류·경고 |
|---|---|
| 편람 핵심어마다 맡은 과제·장면이 있다 | 오류 |
| 평가내용을 설계·환류로 연다(설계 과제, 설계 블록을 단 첫 과제, 평가내용 `서두`, 설계·환류 첫 장면) | 경고 |
| 설계의 축·추진과제를 뒤의 과제·장면이 회수한다, 없는 축을 가리키지 않는다 | 경고 / 오류 |
| 설계의 세부목표·성과지표를 실적으로 회수한다 | 경고 |
| 실행 장면에 왜(문제)·해결·결과가 있다(장면 뒤 주요성과 상자도 결과로 친다) | 경고 |
| 실행 과제마다 주요성과 상자가 있고, 상자에 수치가 있고, 상자 쪽이 과제가 걸친 쪽 안에 있다 | 경고 |
| 지적사항의 회수 위치·배지·참고쪽이 맞고, Ⅰ표 수치가 참고쪽에 같은 값·같은 단위로 있다 | 오류 / 경고 |
| Ⅱ표 세 칸이 차 있고 개선성과 수치가 본문에 같은 값·같은 단위로 있다 | 경고 |
| 제목이 결과 명사로 끝나고 세부목차 한 줄에 들어간다 | 경고 |

수치 대조는 값과 단위를 함께 본다. 2건과 2배는 다르고, "사례2"·"Step1"처럼 이름에 붙은 숫자는 세지 않는다. 한쪽에
단위가 없으면 값만 맞아도 된다. 개소와 곳, 개사·社와 개社는 같은 단위로 본다.
