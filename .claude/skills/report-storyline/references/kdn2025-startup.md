## 2. 한 문단 줄거리

지난해 받은 숙제 네 개(수출성과의 기관 기여도, 데이터 개방·데이터기반행정 '미흡', 기술마켓 제품의 혁신성·연계성,
기술이전 민간 협업의 지속성)로 문을 연다(Ⅰ). 한 장 요약(Ⅱ)은 평가내용마다 ’24년 기반 위에 ’25년에 더한 제도와 전년
대비 배수를 보여 준다. 본문은 네 장이 모두 같은 모양으로 열린다: 환경분석 → (목표) → 추진방향 → 추진과제의 체계도를
먼저 세우고, 뒤 과제와 장면이 그 칸을 같은 순서로 채운다. ① 해외진출은 STEP1 수출지원(성장단계별 수출지원, 수출금융)과
STEP2 해외사업(ODA, 자체 해외사업 동반진출) 두 계단을 오르며 계약추진금액 2.6배와 동반진출 5억원·수주 4.2억원으로
맺는다. ② 데이터는 '수동적 개방에서 능동적 탐색으로' 바꿔 개방 6배를 얻고, 데이터 협력으로 AI 서비스를 만들어
행안부 평가 두 개의 '우수'로 맺는다. ③ 기술마켓은 진입장벽·상시지원·성과중심 3방향을 3개 과제가 하나씩 맡고,
고객 목소리("중복 심사 기다리다가…")에서 Fast Track·공동심의제를 끌어내 등록 31→43건, 구매 5.7→14.6억원으로 맺는다.
④ 특허는 한 과제 안에서 3방향(발굴·홍보·절차)을 가·나·다가 차례로 받아 공개 45%·이전 100%·사업화 3배로 맺는다.

## 4. 복선과 회수: 설계의 칸 = 뒤 과제·장면

일자리 지표는 지표 첫 설계(①-1)가 지표 전체의 목차였다. 이 지표에는 **지표 전체 설계가 없다**. 대신 네 평가내용이
각자 설계로 열리고, 각 설계가 자기 장(章)의 목차가 된다. 회수의 정밀도는 일자리보다 높다(③은 6칸 6장면 1:1).

**① 추진과제 2×2 = 장면 4개**

| ①-1 추진방향 | 추진과제 | 회수하는 장면 |
|---|---|---|
| STEP1 수출지원 - 해외진출 역량강화 | (수출역량) 에너지ICT 중소기업 맞춤형 지원 | ①-2-가 성장단계별 맞춤형 수출지원 |
| | (금융지원) 수출바우처, 협력대출 등 금융지원 | ①-2-나 수출바우처 지원 / 동반성장 협력대출 |
| STEP2 해외사업 - 해외시장 동반진출 | (정부ODA) 정부ODA 사업 연계 해외진출 기회 창출 | ①-3-가 아프리카 ODA 사업 동반진출 |
| | (해외사업) UAE원전, 인도네시아 등 해외 동반 진출 | ①-3-나 UAE 원전 DB / 인도네시아 SEDA |

- 둘째 겹: ①-3 머리의 협업방향 ❶ 컨소시엄 ❷ 기술협력 ❸ 자재활용은 사업명 뒤 괄호로 회수된다: 세네갈(❶+❷),
  UAE(❶+❷), 인도네시아(❶+❷+❸). 사업 카드 안의 KDN 칸·중소기업 칸은 [기업발굴]·[협업추진]·[기술협력]·[공동수급]·[자재납품]
  꼬리표로 ①-1 협업체계(사업추진 한전KDN ＋ 동반협력 중소기업)를 다시 보여 준다.
- ①-1 협업체계의 세 번째 주체 "지자체･금융기관"(금융기관 협력으로 수출금융 지원)은 ①-2-나 협력대출("한전KDN 예탁금(100억원
  규모) 은행 예치")로 회수된다. "지역기업 지원 네트워크 결성"을 맡은 장면은 원문으로 알 수 없다.

**② 추진과제 2×2 = 과제·장면**

| ②-1 추진방향 | 추진과제 | 회수하는 곳 |
|---|---|---|
| 수요 맞춤형 개방체계 혁신 | 수요 기반의 선제적･능동적 데이터 발굴 및 개방 | ②-2 전체(Track-1 〔능동적〕, Track-2 〔선제적〕) |
| | 에너지･무역 데이터 융합을 통한 민간 현안 해결 | ②-3-가(에너지: 원자재 가격 예측), ②-3-나 사례1(무역: 탄소배출·공급망) |
| 民･官･公 데이터 생태계 조성 | 협력기반 데이터 활용으로 공공서비스 가치 창출 | ②-3-나 사례2, ②-3-다 ❶❷(띠 문구 "협력기반 데이터 혁신으로 공공서비스 가치 창출") |
| | 데이터 협력 플랫폼 구축 및 사업화 확대 | ②-3-다 ❸ 중소기업 동반성장 플랫폼 구축 |

- ②-2 제목의 "능동적"과 Track 꼬리표 〔능동적〕·〔선제적〕은 추진과제 문구 "선제적･능동적"을 그대로 쪼갠 것이다.
- ②-1 실행체계(수요분석 ▶ 심사 및 개방 ▶ 활용 및 성과점검)는 ②-2의 Track(수요분석) → ❶ 개방 → ❷ 활용도 개선·점검･환류
  흐름과 겹친다. 1:1 대응을 원문이 표시하지는 않는다.
- 행 머리 ❶ 데이터 개방･활용 확대 / ❷ 데이터 활용도 개선 / ❸ 데이터 품질 개선은 띠 문구 "데이터 개방･활용･품질 ‘3축’"을 회수한다.

**③ 중점과제 3 × 2줄 = 과제 3 × 장면 2 (6:6)**

| ③-1 추진방향 | 중점과제 | 아래 2줄 | 회수 |
|---|---|---|---|
| 진입장벽 최소화 | ① 기술마켓 인증절차 간소화를 통한 중소기업 접근성 제고 | Fast Track 및 공동심의제 도입 / 신청서류 간소화 및 행정 편의 제공 | ③-2 가 / 나 |
| 상시 지원체계 구축 | ② 전담조직･인프라 구성 등 상시 지원 체계 구축 | 전담조직 및 전담인력 상시운영 / 사내 기술마켓 홈페이지 구축･운영 | ③-3 가 / 나 |
| 성과 중심 운영 | ③ 등록･구매 실적 중심의 기술마켓 활성화 | ICT 業 연관 솔루션 중심 유치 / 정책금융 프로그램 제공 및 대내･외 홍보 | ③-4 가 / 나 |

중점과제 문구가 과제 제목으로 거의 그대로 올라간다: "② 전담조직･인프라 구성 등 상시 지원 체계 구축" → 과제 3 "‘전담조직’ 및
‘지원 인프라’ 구성을 통한 상시 기술마켓 지원 체계 구축", "③ 등록･구매 실적 중심의 기술마켓 활성화" → 과제 4 "‘등록과 구매’,
‘수요와 공급’ 매칭을 통한 기술마켓 활성화".

**④ 추진방향 3 = 장면 3**: ① 공개 대상 특허 발굴 체계화 → 가, ② 개방형, 맞춤형 홍보 → 나(온라인 공개(개방형) / 오프라인 공개(맞춤형)
— 방향 문구의 두 형용사가 표의 두 행 이름이 된다), ③ 절차 간소화, 사후관리 강화 → 다(행정 프로세스 효율화 / 기술 중계).

**수치의 복선**

- ③-1 성과목표 2025년 등록 40건·구매 10억원 → 같은 쪽 주요성과 등록 43건·구매 14.6억원. 회수는 같은 단위지만 문구는
  "목표 대비"가 아니라 "전년 대비 39%·156% 증가"다(계산하면 43÷40 = 107.5%, 14.6÷10 = 146%. 원문은 이 비율을 적지 않았다).
- ④-가 Step3 유상 21건·무상 33건 → Step4 선별 18건·14건 → 주요성과 "특허 공개 … 32건". 18 + 14 = 32로 맞지만 원문은
  합을 적지 않아 독자가 더해야 한다.
- ②-2 제목의 "6배"는 같은 쪽 실적1 "5건’24년 → 30건’25년"으로 회수된다. 수치가 제목에 먼저 나오고 본문이 뒤에서 받는다.

| | 민간 활용도 제고 | 1-나, 1-다(사업화) |

- 편람이 동사구 하나(③)나 둘(①②④)뿐이라 일자리 ③처럼 열거 대상을 하나씩 등장시킬 일이 없다. 대신 설계가 편람 문구를
  방향 2~3개로 **쪼개 준다**(③ "활성화" → 진입장벽·상시지원·성과중심).
- 편람에 "전략·계획 수립" 핵심어가 없는데도 네 평가내용 모두 설계로 연다. 설계 과제는 편람 핵심어를 맡기 위해서가 아니라
  장의 목차를 세우기 위해 있다.
- ①의 "동반 해외진출"을 본문은 "수출 지원"까지 넓혀 읽는다(①-2 전체가 수출박람회·인증·바우처). Ⅰ표 J1 지적("수출성과가 중소기업
  실적에 기반하며 기관 기여도가 불명확")이 바로 이 넓힘을 겨눈다.
- ④의 "실용신안"은 띠·세부목차·Ⅱ표 머리의 편람 문구에만 있고 본문은 "특허"만 다룬다(인쇄 56쪽).

## 6. 장면의 문법

장면 하나는 **문제 → 해결 → 결과**를 한 번 돈다. 이 지표는 문제를 세 가지로 연다: 칸마다의 **니즈**(①-2-가), 고객의
**인용**(③-2), 한 줄 **추진배경 띠**(③-3, ③-4). 결과는 장면 맨 아래 **추진실적·추진성과 라벨 줄**이나, 장면 단위 주요성과
상자(④)가 맡는다.

| 장면 | 문제(왜) | 해결(어떻게) | 결과(얼마나) |
|---|---|---|---|
| ①-2-가 | 지원대상 3단계별 니즈(인증·시장조사 / 바이어 매칭 / 플랫폼 입점) | 단계별 추진내용 + 〈개선〉 전후 줄 | 단계별 추진성과(인증 10건, 계약추진 2.6배, KOMPASS 7건) + 대표사례 2 |
| ①-3-가 | 〈발굴노력〉 세네갈 인프라 설계 자문 역할 기업이 필요 | 지원-협업 프로세스(→), KDN＋중소기업 역할, 〈기존〉→〈신규〉 2줄 | 아프리카 시장 진출(사업규모 5억원), 약 500만불 사업확대 예정 |
| ②-2 | (추진배경) 「수동적 개방」에서 「능동적 탐색」으로 대전환 | Track-1 ＋ Track-2 ▶ 3축 | 개방 6배, 활용률 20% 향상, 품질 1등급 |
| ②-3-가 | (추진배경) 많은 인력·시간 소요 ＋ 전기요금 인상 요인 완화 필요 | ❶ 협력체계 ▶ ❷ 데이터 기반 ▶ ❸ AI 서비스 | (혁신) 예측정확도 94%, (사회) 2,500만 가구 전기요금 부담 완화 |
| ③-2-가 | “중복 심사 기다리다가 판로 개척의 골든 타임을 놓치고 있습니다.” | 〈신규〉 Fast Track·공동심의제: 〈기존〉 → 〈개선〉 | 〈속도개선〉 Fasct Track 17건, 공동심의 20건 / 〈등록확대〉 |
| ③-2-나 | “인증 신청을 위해 준비해야 할 서류가 너무 많아…” | 서류 12종 → 5종, OCR 수기 → 자동입력 | 〈효율화〉 서류 종류 58% 축소 / 〈활성화〉 |
| ③-4-가 | (추진배경) 수동적 인증 방식으로 기관 業과 무관한 제품 인증 | 추진내용 4 + 사례 2(개선 전 ▶ 개선 후) | ICT분야 14종 신규 등록 |
| ④-가 | (설계 추진배경에서 이어 받음) | Step1 598건 ▶ Step2 기준 완화 ▶ Step3 SMART5 ▶ Step4 평가회·심의회 | 후보 112→318건, 선별 21→18건·33→14건, 주요성과 22→32건 |

- 결과 줄에 **라벨 배지**를 붙여 효과의 종류를 이름 짓는다: 〈속도개선〉〈등록확대〉, 〈효율화〉〈활성화〉, 〈효율성〉〈판로확대〉,
  (혁신)(사회), 〈효과〉, 〈실적〉. 라벨 두 개가 한 쌍으로 "빨라졌다 + 많아졌다"를 말한다(③-2-가, ③-2-나, ③-3-나).
- ①-2-가의 3단계 표는 "지원대상 → 니즈 → 추진내용 → 개선 → 추진성과"가 행 머리로 박혀 있어 한 장면 안에서 문제→해결→결과가
  세 번(단계마다) 돈다.

## 7. 지적사항 환류: 숙제 검사의 동선

## 8. Ⅱ표: 시간의 서사

평가내용마다 세 칸이다. **’24년도까지의 실적**(1~2줄) → **’25년도 주요 실적**(2줄) → **전년대비 개선성과**(1~3줄).

- 개선성과 8줄이 **모두** ’24→’25 전후 비교에 배수를 붙인 형식이다: "등록 : 31건’24년→43건’25년(1.4배 증가)". 외부 인정·최초는
  개선성과 칸에 없고, 외부 인정(공공데이터평가 2년 연속 '우수')은 ’25년도 주요 실적 칸에 들어갔다.
- ’24년도까지의 실적 칸이 ④에서는 숫자(기술 공개 22건･기술이전 2건, 사업화 4건)로, 개선성과의 ’24년 값과 같다. 기반과 비교 기준이 한 줄로 이어진다.
- ’25년도 주요 실적 칸은 그해 새로 만든 제도 이름이다(수출금융 지원제도 신설, Fast Track 및 기관 공동심의제 도입, 평가회 신설).
- 배수 표기가 본문과 다르다: Ⅱ표 1.4배·1.5배·2배 ↔ 본문 39%·45%·100%. 같은 사실을 두 단위로 적었다(11절).

  ‘ ’(작은따옴표)로 키워드를 묶는다(③-3, ③-4).
- 끝말: 구축·지원·창출·확대·해결·강화·제고·활성화(과제), 강화·마련·동반진출·창출·구현·제공·조성·지원·향상·고도화·견인·확대(장면).
  "해결·구현·제공·견인·동반진출"은 점검기의 결과 명사 목록에 없어 경고가 난다(10절 표 아래 참고).

  일자리(「KDN-취업드림(Dream)」 등)보다 적다.

## 11. 원문에서 보이는 빈틈 — 새로 쓸 때 피할 것

1. **J3 Ⅰ표 수치가 참고쪽에 없다.** "R&D 성과로 기술마켓 인증제품 2건 선정, 혁신제품 지정 1건 추진"(49쪽)은 55쪽에 없다. 55쪽 ③-4-가
   사례2는 한 회사((주)쿤O)의 "기관 인증 제품 등록 추진(1차 심의 완료’25년)"과 "공동 R&D 성과의 기술마켓 진입 및 혁신제품 지정 추진"뿐이다.
   점검기는 수치를 단위까지 맞춰 보고 "사례2"처럼 이름에 붙은 숫자는 빼므로, 2건·1건이 없다고 경고한다.
2. **같은 수치가 단위를 바꿔 나온다.** 구매 5.7→14.6억원은 54쪽 "156% 증가", 55쪽·Ⅱ표 "2.6배". 등록 31→43건은 54쪽 "39% 증가", Ⅱ표 "1.4배".

3. **Ⅱ표 ② "데이터 분석･활용 : 5건’24년 →16건’25년(3.2배 증가)"의 ’24년 5건은 본문에 없다.** 53쪽에는 "데이터분석･활용 실적 창출(16건)"만 있다.
   52쪽의 "5건’24년"은 데이터 개방 건수다.
4. **J2 참고쪽이 하나다.** 지적의 후반 "데이터기반행정 평가 '미흡'"을 푼 곳은 53쪽 ②-3-다 ❷(배지도 있음)와 53쪽 주요성과인데 Ⅰ표 참고는 p.52만 적었다.

   성과(5개社 50백만원, 수출액 336백만원, 13개社 16백만원)는 장면 안에만 있다.
