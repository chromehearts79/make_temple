## 2. 한 문단 줄거리

지난해 받은 숙제 다섯 개(지역채용, 청년인턴, 민간 직접일자리 감소, 사회형평 채용, 여성 교육)로 문을
연다(Ⅰ). 한 장 요약(Ⅱ)에서는 ’24년까지 해 온 일 위에 ’25년에 더한 일과 그 결과 수치를 평가내용별로
보여 준다. 본문은 「일자리 혁신 전략」이라는 설계도(①-1)로 시작한다. 설계도는 공공·민간·사람 중심
3축에 추진과제를 3개씩 두고, 이후 목차가 이 9칸을 차례로 채운다. 공공 축은 채용여력을 최대로 확보해
’23년 이후 최대 규모(102명)를 뽑고 인턴·공정·공감 채용으로 질을 높인다. 민간 축은 관리체계(②-1)를 따로
세운 뒤 본업연계(4,607명)·상생기반(112명)·근로환경 개선으로 일자리를 만든다. 사람 중심 축은 지적사항을
4대 개선과제로 바꿔 사회형평 채용을 넓히고, 여성 인재를 채용·육성·대표성 세 단계로 키운다. 쪽마다
주요성과로 맺고, 고용노동부 장관상·남녀고용평등 우수기업·문체부 장관상 같은 외부 인정으로 끝낸다.

## 4. 복선과 회수: 세 겹의 예고편

이 지표의 가장 큰 서사 장치다. 설계 과제가 내놓은 칸을 뒤의 과제·장면이 **같은 말, 같은 순서**로 채운다.

**지표 단위 — ①-1 추진과제 3×3 = 나머지 목차**

| ①-1 축 | 추진과제 | 회수하는 과제·장면 |
|---|---|---|
| 공공 일자리 확대 | 정규직･인턴 공공채용 확대 | ①-2 최대 규모 채용, ①-3 인턴 |
| | 채용 전 단계 직무중심 체계 구축 | ①-4-가 [공정] 채용 全단계 직무중심･공정 채용 체계 구축 |
| | 지원자 소통기반 공감 채용 | ①-4-나 [공감] 지원자와 소통하며 공감하는 채용 문화 |
| 민간 일자리 창출 | 본업연계 일자리 창출 | ②-2 본업연계를 통한 민간 일자리 창출 |
| | 상생기반 일자리 창출 | ②-3 중소･협력기업 및 지역인재 성장 지원 |
| | 지속가능 일자리 환경조성 | ②-4 지속가능한 일자리 생태계 조성 |
| 사람 중심 채용 | 제도 개선기반 취약계층 채용 | ③-1 채용제도 개선 및 신규 프로그램 |
| | 사회형평적분야 일자리 창출 | ③-2 취약계층 일자리 창출 |
| | 양성평등 체계 기반 여성 대표성 실현 | ④ 전체 |

**평가내용 단위 — ②-1과 ④-1은 자기 장(章)의 장면을 예고한다**

- ②-1 추진방향 3(본업연계형·상생기반형·지속가능 환경)과 추진과제 6 → ②-2 가 [핵심사업]·나 [미래성장], ②-3 가
  중소･협력기업·나 지역인재, ②-4 왼쪽 근로환경·오른쪽 근로복지. 추진과제 6개가 장면·칸 6개와 1:1이다.
- ④-1 환경분석 (채용)·(육성)·(보직) → 개선방향 ①②③ → ④-2 가 `채용`·나 `육성`·다 `대표성`.

**장면 단위 — 갈래가 장면의 목차다**

- ①-2-가 추진방향 ①결원예측 ②정부협의 ③고용유지 → 세 갈래 상자와 갈래별 성과 줄.
- ③-1-가 4대 개선과제 ①제도 ②신설 ③소통 ④협약 → 아래 4분면이 같은 번호로 채운다.

**수치의 복선** — ①-1 세부목표의 민간 주요사업 ’25년 4,109명은 ②-2 주요성과의 "민간 일자리 4,607명
창출(목표 112.1% 달성)"로 회수된다(4,607 ÷ 4,109 = 112.1%). ②-1 성과지표 3개도 ②-2·②-3·②-4의 실적으로 돌아온다.

## 5. 편람 문구 분해

편람 문구를 명사구로 쪼개면 각 조각을 맡은 과제가 하나 이상 있다. "노력과 성과"는 모든 과제가 맡으므로
따로 세지 않는다.

| 평가내용 | 편람 핵심어 | 맡은 과제·장면 |
|---|---|---|
| ① | 추진 전략 및 계획의 수립 | 1 |
| | 신규채용 등 일자리 창출 | 2, 3 |
| | 공정채용 | 4(가 공정, 나 공감, 다 비정규 공정성) |
| ② | 민간부문의 일자리 창출 기여 | 1~4 (방향 3개로 나눔) |
| ③ | 고졸자 | 1-가(제한채용, 마이스터고 MOU) |
| | 지역인재 | 2(대상별 표 행) |
| | 장애인 | 1-가(장애인고용공단), 2(행) |
| | 자립준비청년 | 1-가(간담회), 2(행) |
| | 저소득층 | 2(기초생활수급자 행) |
| ④ | 여성임원･관리자 확대 | 1, 2-나, 2-다 |
| | 여성채용 확대 | 1, 2-가 |
| | 여성인력 활용 | 1, 2-나 |
| | 여성대표성 제고 | 1, 2-다 |
| | 양성평등 실현 | 2-다(캠페인, 남녀고용평등 우수기업) |

③처럼 편람이 대상을 열거하면 본문이 열거된 대상을 빠짐없이 등장시킨다. ③-2 대상별 표는 편람 순서를 따르지 않고
「기관 최초」 성과가 난 기초생활수급자를 맨 위에 둔다.

## 6. 장면의 문법

장면(가·나·다) 하나는 **문제 → 해결 → 결과**를 한 번 돈다. 문제가 장면 안에 없으면 앞의 설계(환경분석)나
지적사항이 그 몫을 한다.

| 장면 | 문제(왜) | 해결(어떻게) | 결과(얼마나) |
|---|---|---|---|
| ①-2-가 | 환경분석: 불시결원 多, 신입 퇴직 증가 | 추진방향 3 → 갈래별 (현황)→(개선) | 충원율 100%, 정원 58명, 퇴사율 45.5%↓ |
| ①-2-나 | (현황) 인력 부족, 인지도 부족 | (개선) [내부] 지역전문사원, [외부] 홍보 | 지원자 6배, 채용 4배 |
| ①-4-나 | 설문으로 뽑은 지원자 목소리 "전형별 절차가 헷갈려요", "왜 탈락했는지 궁금해요" | 절차 간소화, 편의 지원, 탈락자 피드백 | 지원자 148%↑, 만족도 2.3점↑ |
| ③-1-가 | (지적) 정규직 채용실적 미흡, (환류) 별도 채용 필요 | 4대 개선과제 | 정규직 4→7명, 인턴 0→23명 |
| ③-1-나 | (추진배경) 재도약 기회 제공 | 대상 14명, 프로그램 4단 | 취업성공 2명, 만족도 93% |

큰 장면은 2~4개의 **갈래**로 나눈다. 갈래마다 작은 문제→해결→결과를 두고, 끝에 굵은 성과 줄을 단다
(①-3 4분면, ②-3-가 4분면의 [지원]·[성장]·[일자리] 꼬리표).

### 형식 카탈로그 — 내용의 모양에 맞춰 고른다

| 내용의 모양 | 형식 | 예 |
|---|---|---|
| 전략·체계를 세움 | 체계도: 배경 → 비전·목표 → (세부목표 표) → 축 → 과제 → 성과지표 | ①-1, ②-1 |
| 문제를 갈래로 진단 | 환경분석 N열 → 개선방향 N | ④-1 |
| 한 문제를 고침 | 현황 ▶ 개선 흐름 + 2분할 | ①-2-나 |
| 여러 수단을 나란히 씀 | 2~4분면(＋ 연결), 칸마다 성과 줄 | ①-2-가, ①-3, ②-3-가, ②-4, ④-2-다 |
| 절차가 있는 업무 | 단계(서류·필기·면접) × 관점(공정·직무) 표 + 성과 열 | ①-4-가 |
| 대상을 열거함 | 대상별 표(대상 · 노력 · 성과) | ③-2 |
| 생애·성장 단계 | 단계별 표(초중고 → 대학·취준 → 구직단념) | ②-3-나 |
| 사업 연계 실적 | 사업분야 × 대상사업 ▶ 창출실적(직접·간접) | ②-2 |
| 고객 목소리에서 출발 | 의견수렴 ▶ 주요 의견(인용) → 노력·성과 표 | ①-4-나 |
| 지적사항에서 출발 | 지적·환류 ▶ N대 개선과제 → N분면 | ③-1-가 |
| 신설 프로그램 | 띠 표: 추진배경 · 참여대상 · 프로그램 · 성과 | ③-1-나 |
| 지표 몇 개로 맺음 | KPI 막대 타일 | ④ 주요성과 |

## 7. 지적사항 환류: 숙제 검사의 동선

1. **Ⅰ표**: 지적사항 → 조치 ∙ 2개 → ☑(재현본에서는 ▣) 정량 성과 1~3줄(굵게) → 참고쪽.
2. **본문 배지**: 참고쪽의 과제·장면 제목 옆에 「지적사항 개선」. 배지는 지적을 푼 가장 작은 단위에 단다:
   과제(①-3, ②-2, ③-1, ③-2), 장면(①-2-나), 표의 한 행(④-2-나 Connect&Grow).
3. **같은 수치 반복**: Ⅰ표의 성과 수치가 본문과 주요성과에 다시 나온다(J1 지역전문사원 37→227명, 4→16명은 Ⅰ표와
   30쪽 주요성과에 그대로).
4. **풀이 문구 대응**: J3 조치 "일관된 산정 및 집계 기준 정비"는 32쪽 주요성과 첫 줄 "산정･집계 기준 정비를 통한 관리
   체계화"로 돌아온다.
5. 외부 지적이 없어도 "※ 국회, 감사원 등 외부 지적사항 : 해당사항 없음"을 적는다.

## 8. Ⅱ표: 시간의 서사

평가내용마다 세 칸이다. **’24년도까지의 실적**(이미 있던 기반) → **’25년도 주요 실적**(올해 새로 더한 일) →
**전년대비 개선성과**(정량). "작년에도 했다"가 아니라 "작년 기반 위에 올해 이것을 더해 이만큼 나아졌다"를 한
줄로 보여 준다. 개선성과 칸 8줄 가운데 7줄이 ’24→’25 비교, 목표 대비, 최초, 외부 수상이다. 정성 문구는 ②의
"맞춤형 프로그램 운영으로 참여자 역량 강화" 하나다.

| 조직 다양성 강화를 위한 「여성 인재 활용 및 대표성 제고」 개선방향 수립 | [목적] + 「체계명」 + 수립 — 설계형 |
| 적극적 채용여력 확보 및 제도개선 노력으로 「’23년 이후 최대 규모」 채용 달성 | [수단]으로 + 「강조 성과」 + 달성 |
| 인턴운영 체계 확립 및 제도 내실화를 통한 청년 일자리 창출 | [수단]을 통한 + [결과] |
| 직무 능력중심 「공정」 채용 및 지원자와 소통하는 「공감」 채용 선도 | 「키워드」 두 개의 대구 → 장면 가 [공정], 나 [공감] |
| 여성 인재 전주기 육성･활용 고도화로 성별 불균형 해소 및 양성평등 경영 가치 확산 | [수단]로 + [결과1] 및 [결과2] |

- 설계 과제는 **수립·고도화**로, 실행 과제는 **달성·창출·선도·조성·마련·확산**으로 끝난다.
- 「 」는 제목당 한두 개, 체계 이름이나 강조할 성과에만 쓴다.
- 장면 소제목은 `[태그] 수단 + 결과`. 태그는 축이나 편람 키워드다: [공정]·[공감], [핵심사업]·[미래성장], `채용`·`육성`·`대표성`.
- 프로그램에는 이름을 붙인다: 「KDN-Job담회」, 「KDN 인재발굴단」, KDN Interviewer, 「KDN-취업드림(Dream)」,
  「KDN-IT We로」, Connect&Grow. 이름 붙은 활동은 기억되고 기관 고유의 것이 된다.

## 11. 원문에서 보이는 빈틈 — 새로 쓸 때 피할 것

`storyline.py check`가 원문 스토리라인에서 경고 8건을 낸다. 오류는 없다. 경고와 손으로 찾은 항목을 합치면:

1. **Ⅰ표 수치가 참고쪽에 그대로 없다.** J3 "민간 직접 일자리 2,235→2,314명"은 32쪽에 없다. 32쪽 막대는 전력계통·ICT
   직접 1,985→2,236명, 미래성장 직접 78명이다. 2,236 + 78 = 2,314라 합은 맞지만 독자가 더해야 하고, ’24년
   2,235명의 구성은 나오지 않는다. Ⅱ표 ②도 같은 수치를 쓴다.
2. J2 "인턴 수료생 15명 취업 성공"은 31쪽 과제 3에 없다(31쪽의 15명은 면접관 자격취득 인원이다).
3. J4 "법정기준(3.8%)"은 34쪽에 없고 "4.75%(목표 대비 0.95%p↑)"로만 나온다(4.75 − 0.95 = 3.8).
4. ①-1 세부목표 5행 가운데 본문에서 목표 대비로 맺은 것은 민간 주요사업 하나다. 공공 정규직채용 ’25년 125명과
   신규채용 102명이 같은 기준인지 설명이 없다. 체험형인턴 110명·민간지원 211명과 같은 이름의 실적도 이 9쪽에
   없다(②-3-나의 ‘직무연계형 체험 인턴 102명’이 같은 대상인지는 원문으로 알 수 없다).
5. ②-1 성과지표는 "근로개선 프로그램 지원실적(건)"인데 ②-4 실적은 개社·억원·명 단위다.
6. 33쪽 주요성과 112명은 과제 3의 12+33+15+23명에 과제 4의 29명을 더한 값으로 보인다. 문구는 "중소･협력기업 및
   지역인재 성장을 통한"이라 과제 4의 몫이 섞인다.
7. 세부목차는 "Ⅲ. 세부 평가내용별 주요 추진실적", 30쪽 제목은 "Ⅳ. 세부 평가내용별 추진실적"이다.
8. 편람 ③이 처음 꼽은 "고졸자"는 34쪽 대상별 표에 행이 없다. 다른 곳(③-1-가, ①-3)에서 다룬다.
